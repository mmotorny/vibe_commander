# Volkov Commander: the design

A short book on how Volkov Commander 4.05, a two-panel file manager for
DOS, fits its features into a 65,090-byte `.COM` file, a 64K segment of
data and 256 bytes of stack, and gives back all but 12,690 bytes of
itself while a command runs. It is written for a reader who knows a
modern toolchain and may remember a little DOS. The code shown is the
portable C of `src/portable_c/`, a faithful C rendering of the
original; Volkov's assembly in `src/asm/` is quoted where a trick only
shows there. The screens are the original's own, as it draws them.
