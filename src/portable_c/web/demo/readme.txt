Welcome to Vibe Commander
=========================

This is drive D:, the demo. Its files were written for the project, and
you may change them: every change is made on the page's server as you
make it.

A few things to try:

  F3      view the file under the cursor
  F4      edit it
  F5      copy it to the other panel
  F6      rename or move it
  F7      make a directory
  F8      delete
  Ctrl-O  the panels off and on
  Alt-F1  another drive for the left panel (C: is where the program
          keeps its own files, in C:\VC)
  F10     leave

Enter on a file opens it in a new tab of the browser. Your own files
come in by the Upload button, or by dragging them onto the page: they go
into the current directory.

Commands cannot be run in a web page.
